# 彈design — 讓圖片自然動起來

版本：**v1.0.7**

純前端、零外部依賴（原生 WebGL + Canvas2D）。直接用瀏覽器開 `index.html` 即可使用。

## 結構
```
整體（動作組、強度、彈跳搖擺；帶動全部）
 └ 圖層（圖片 / PSD 圖層；本身不動）
    └ 軀幹（固定錨）
       ├ 頭 → 側髮 / 後髮 / 呆毛 / 耳朵
       └ 手臂、尾巴（可切成獨立圖層放到後方）…
```
- **範圍**：每個部位有「核心」（錨點周圍或遮罩）與「牽連範圍」（核心外越遠影響越小）。
  先分核心（子部位優先），剩下的像素再依牽連範圍分配，最後剩餘歸圖層本身。
- **錨點**：第一個 = 支點，之後依點擊順序連成一條鏈；擺動時每一節依序彎曲。
- **獨立圖層**：把部位切出來、調前後；後方會自動延伸補色，前方會自動補底圖空洞；可轉成真正的圖片圖層再繪圖 / 匯出 / 取代。
- **PSD**：讀取 8 位元 RGB / 灰階、圖層群組、顯示狀態、不透明度、中文圖層名稱（RLE / ZIP 壓縮）。

## 2.0 新增
- **儲存 / 開啟專案**（`.彈design.png`）：圖片、遮罩與所有設定存成一個檔。檔案本身是一張作品縮圖（PNG），檔案總管可直接預覽，專案資料放在 PNG 的私有區塊 `tnDz` 裡；舊的 `.puppet` 也能開，舊版資料會自動補齊新欄位。
- **立體（偽 3D）**：參數區分成「動態」「立體」兩個分頁，共用部位、錨點與範圍。
  整體設定轉向 / 俯仰 / 深度感；各部位設定深度（-1 後 … +1 前）與壓縮。前方部位往轉向方向移、後方反向，支點附近漸弱。
  - 轉向與俯仰各自有「角度 / 次數 / 相位」；次數相同、相位差 8 = 繞圈，次數 2 倍 = 點頭。
  - 深度：選取部位 / 圖層後，拉部位區上方的「深度」橫條（立體啟用時顯示）；新部位預設沿用所在圖層的深度。
  - 深度筆（G）：在選取的部位 / 圖層上塗出不同深度（有塗 = 淺、無塗 = 深），深度條變成雙端拉桿設定兩端；筆刷有大小、柔化、不透明度。
  - 試轉：預覽畫面下方（左右）與右方（上下）的拉桿，編輯時直接拖曳看轉向效果，雙擊歸零。
  - 圖層模式：圖片圖層與群組都有深度，群組帶動裡面的圖層；可「依圖層順序產生深度」。
  - 臉部精細：頭分成「臉」與「頭側面」，頭的外緣不動。側面壓縮 = 轉過來的一側展開、轉過去的一側壓縮；臉部曲度 = 臉本身中間比邊緣多移一點。畫面上可拖曳中線兩端、中心、頭寬、臉寬、半高。
  - 轉動範圍：每個物件用雙端拉桿設定整體轉到最左 / 最右（最上 / 最下）時自己轉到多少（靜止時都是 0）。
    頭底下的部位（眼睛、鼻口…）的深度差 = 相對曲面的凹凸：眼睛負值（凹）、鼻口正值（凸）。
  - 試轉：立體分頁頂端的「左右 / 上下」拉桿，在編輯模式下固定一個轉向姿勢預覽，調整立體參數時不會自動播放。
- **自動綁定**（部位列的魔杖）：多圖層依圖層名稱判斷類型（前髮、後髮、五官、眼、手、腿、身體、背景…），把頭部圖層收進「頭」群組並開臉部精細，頭髮 / 手臂自動加鏈、給深度起點；單張圖替已畫好範圍、還沒有錨點的部位自動放錨點。已設定的深度不會被覆蓋。
- **時間軸**（播放列的「時間軸」按鈕）：選取部位 / 圖層，用關鍵影格編輯位移 X / Y、翻轉（以支點為軸像翻書頁）、前後順序（切換瞬間自動淡出，做遮擋切換）、透明度，每條都有拉桿。拖到某個時間點拉拉桿就會建立關鍵影格；畫面上的黃色菱形把手可直接拖曳整個部位（寫入位置關鍵影格）；◆ 拖曳移動、雙擊或 Delete 刪除。
- **裁切（C）**：選取圖片圖層，拖曳 8 個把手 / 框內移動，框外變暗；Enter 套用、Esc 取消。
- **畫布大小**：裁切工具（C）沒選圖片圖層時就是畫布模式（選了圖片圖層可切換「圖層 / 畫布」）：拖把手或在框外直接框選新範圍，往外拉可加大，「貼齊內容」一鍵縮到內容；預覽中畫布外淡淡變暗。
- 工具詳細改成工具列下方的細橫條，可收起，點工具會再出現；左右面板角落的 « » 可收合 / 展開。
- 部位樹圖示：圖片 = 圖片、頭 = 頭、有編輯遮罩 = 紅圈、只有錨點鏈 = 綠色鏈、群組 = 資料夾。
- 多圖層的「頭」和單張圖一樣是頭部件（範圍設為無，當父層帶動底下的圖層）；舊檔的頭群組會自動轉換。
- 說明文字改成滑鼠停留提示。
- 範例：白髮女孩單張、白髮女孩分層 PSD（自動綁定）。
- 新部位類型：前髮、五官、眼睛、腿。
- 圖層的「物件屬性」：多圖層的圖層可指定類型（頭、軀幹、頭髮…），套用動作預設、用錨點工具放支點與鏈，並可在屬性面板設定父層，當其他圖層的父層一起帶動。
- 獨立圖層：子部位優先取得像素；補色只做在上下層交界的帶子（顏色取兩邊平均、不超出原圖），可調「補色寬度」。
- 邊緣柔化只往外，多邊形的尖角不會被吃掉；多邊形可按住拖曳自由描邊、Backspace 刪上一點。

## 工具
| 工具 | 鍵 | 用途 |
|---|---|---|
| 選取 | V | 點選部位（切到編輯模式）、拖曳錨點、右鍵選單 |
| 變形 | T | 圖層移動 / 縮放 / 旋轉 / 裁切；取代圖片時對齊（需選取影像圖層）|
| 錨點 | A | 放錨點；雙擊或右鍵刪除 |
| 遮罩筆 | B | 加入 / 擦除範圍，可調筆刷柔化（Alt 反向，X 切換）|
| 多邊形 | L | 描點圈選範圍 |
| 繪圖 | D | 直接在圖層上繪製 / 擦除，可調柔化（需選取影像圖層）|

部位樹的圓點 = 動 / 不動；圖層順序的眼睛 = 顯示 / 隱藏；每個參數左側圓點可單獨關閉該數值。
速度由 BPM 決定（每分鐘幾個完整循環，60 BPM = 一秒一循環），FPS 只影響流暢度與輸出幀數。延遲單位為 1/32 循環。

空白鍵：播放 / 暫停 · `← →` 逐幀 · `[ ]` 筆刷大小 · Delete 刪除錨點或部位 · Ctrl+Z / Ctrl+Y

## 輸出
右上「輸出」：
- **MP4（H.264）/ WebM（VP9）**：用瀏覽器的 WebCodecs 逐格編碼，不是即時錄影，不會掉格；不支援的瀏覽器才退回錄影。背景黑 / 白 / 綠幕。
- **APNG**：全彩、半透明邊緣平滑、可透明，多數瀏覽器與通訊軟體可播放；檔案比 GIF 大。
- **GIF**：256 色；幀率選 25 / 50 / 20（每格時間是 1/100 秒的整數倍，播放才均勻）；調色盤從整段動畫取樣並微調，顏色較準。修正方法見 `docs/gif-export-fix-prompt.md`。
- **PNG 序列（ZIP）**。
可設循環次數、尺寸與邊距。

## 頭部定位（HeadRig）

選取「頭」→ 參數「立體」→ 頭部定位（兩個白髮女孩範例會自動建立）。所有設定集中在這裡，畫面上直接拖：

- **中心**（黃）：轉軸位置；**頭頂**（黃）：高度＋中線方向（歪頭）。自動建立時，有舊的臉部精細就原樣沿用（轉向效果不變），沒有就由兩眼中點與眼線決定；之後可按「依兩眼對齊中線」。
- **頭寬**左 / 右（黃）：中線到頭髮最外側；**臉寬**左 / 右、**下巴**（白）：兩者之間是轉向時展開 / 壓縮的頭側面，下巴以下往脖子漸弱。左右可以不對稱（3/4 側臉）。
- **五官**（粉紅）：左右眼、眉、鼻、嘴，各自拖位置，白色方塊調範圍（左右同步只同步大小）。範圍內整塊跟著臉走、不被曲面扭曲；「五官立體」讓鼻子往轉向側多移、眼睛略凹。
- 試轉 / 預覽有角度時，定位點顯示在變形後的位置，拖曳的位移換算回靜止位置。
- 自動找五官：眼 = 深色與眼白同時密集處；嘴 = 明顯偏紅處（找不到才用深色）；只是起點，請拖到正確位置。
- 分層：圖層遮擋（遠側側髮換到臉底下）、遠側淡出（耳朵）在「範圍數值」裡。
- **繪圖**：可以畫到圖層原本範圍外（整張畫布內），結束時圖層圖片自動擴大並保持位置。

## 軟體選單與快捷鍵

- 點左上角「彈design」：開啟、儲存、輸出、範例、復原 / 重做、快捷鍵設定、說明。
- 快捷鍵設定：點按鍵欄位後按下新的組合（Esc 取消、Backspace 清除），同一組合只能給一個功能；存在這台電腦的瀏覽器（`localStorage` 的 `tan.keys`）。
- 圖層繪圖的滴管：顏色旁的滴管按鈕，吸完自動結束；也可以按住 Alt 點畫面吸色。

## 關鍵影格

- 按播放列的「時間軸」打開：鋪在最底下（蓋住左邊的圖層區），上緣可拖曳調高度；打開時不會暫停播放。
- 軌道：位移 X / Y、旋轉（可超過一圈）、縮放 X / Y、透明度、翻轉、前後；右側動作參數旁的 ◇ 可替參數打影格（◇ 沒有動畫、◈ 有動畫、◆ 播放頭在影格上，再按刪除）。
- 預覽模式下有影格的數值 = 在播放頭打影格；編輯模式改的是靜止值（動畫跟著走）。
- 播放中：按 ◆ 在當下打一格；拖拉桿或畫面上的移動 / 旋轉把手時會先暫停，放開後繼續播放（影格落在按下那一刻）。
- 曲線（每段各自設定，影格右鍵）：平滑（預設，經過影格不停頓、循環接縫連續）、緩動、線性、緩入、緩出、保持；標題列「全部曲線…」一次套用。
- 程序動作（擺動、彈跳、慣性）疊在影格之上。

## 圖層與部位

- 圖層可以直接當部位：在沒指定類型的圖層上用錨點工具放第一個點，會問「這個圖層是什麼？」，選了就套用該類型的預設動作，繼續點就是擺動鏈。
- 物件屬性 / 新增部位用分類選單：頭部（頭、前髮、瀏海、頭髮、後髮、髮翹、呆毛、獸耳）、五官（臉、眼睛、鼻子、口、眉毛）、軀幹（固定錨）、身體（手臂、上臂、小臂、手腕 + 手、腰臀、腿、大腿、小腿）、其他（尾巴、飾品翻轉 / 垂墜、固定物件、自訂）。細分類型沿用基底類型的行為，預設參數參考「白髮女孩（分層）」範例。
- 圖層區：縮圖、「深度 · 類型」、名稱；頂端固定不透明度與深度拉桿（沒啟用立體時深度灰掉）。Ctrl / Shift 多選後按資料夾按鈕組成群組，選群組用變形工具（T）整組移動；群組列右鍵可解散。
- 顯示：父層圖片隱藏不影響底下的圖層（只有群組隱藏會一起隱藏）。眼睛與動 / 靜圓點可以按住往下拖，一次切換一整排。
- 刪除部位只刪部位本身，底下的圖層接回上一層。
- 依循父層：子層可以選「整體（跟著父層變形）」或「父層某個錨點的位移」。

## 頻率與曲線

- 整體的「左右 / 旋轉」「上下 / 壓扁」與部位的「旋轉頻率」、鏈的擺動頻率都能以 0.5 為單位設定；旁邊的小扳手打開曲線面板：形狀（往復、平滑、等速、彈跳）、頻率、緩動、兩端停頓、去回快慢、衝過頭、相位、來回鏡像、下壓深度，上方即時畫出兩個循環的曲線。
- 頻率不是整數時循環接點會斷開（不自動延長）；輸出對話框會列出是哪一項。

## 時間軸長度、縮放、算 BPM

- 時間軸標題列「＋ 增加一次循環」：總長 = 單一循環 × 循環數，最後一個循環的影格照原節奏複製到新循環；「−」刪掉最後一個循環。程序動作（擺動、彈跳）仍以單一循環為週期。
- 「縮放」拉桿（或在時間軸上 Ctrl + 滾輪）橫向放大，可以左右捲動，左欄固定不動。
- 整體 → 時間軸 →「算 BPM」：跟著節奏點按鈕，取最近四次間隔的平均；測到後按「套用」，↻ 重測。

## 眨眼
- 眼睛圖層（屬性面板 →「眨眼」→ 啟用眨眼），或快速建模時把圖層指定為「眼睛（會眨眼）」「閉眼差分」「眼皮（遮擋用）」。
- 素材：眼睛圖層（必要）＋閉眼差分（選用）＋遮擋（選用：眼皮圖層或底色）。素材圖層會自動隱藏，只用來產生眨眼。
- 做法：每一欄找出眼睛的上下緣與閉合線（有閉眼圖時用它的位置），上睫毛整條往下移、眼珠往閉合線收、下眼瞼往上收，快閉上時換成閉眼圖；沒有閉眼圖時，上睫毛壓成一條線當閉眼。預先算成 10 個閉合程度，播放時換貼圖（跟著頭一起變形）。
- 遮擋：底下的圖原本也畫著眼睛時才需要；「用底色」會從眼睛周圍自動取膚色，也可以自己選。
- 眼睛畫在圖上（沒有單獨的眼睛圖層）：選那個圖層 →「從這張圖圈出眼睛」，用套索圈兩眼 →「完成」。範圍內跟膚色差很多的（睫毛、眼珠）和偏冷的亮色（眼白）算眼睛，做成「眼睛（眨眼）」圖層，完全跟著原圖變形；遮擋自動用「自動補膚色」（只從像皮膚的地方往內補，不會吃到頭髮）。
- 範例「blink test・眨眼」：分層眼睛＋閉眼差分，一次一般眨眼、一次連眨兩下。
- 微調：閉合線（沒有閉眼圖時）、上睫毛厚度、下眼瞼；「試閉」拖曳可以直接看閉合過程。
- 時間：時間軸的「眨眼」列，◆ 在播放頭加一次（已有就刪除），拖曳移動、雙擊刪除、右鍵換樣式。樣式（秒數固定，不受 BPM 影響）：一般、快速、慢眨（睏）、連眨兩下、瞇眼。增加循環時眨眼會一起複製。

## 存檔
- 瀏覽器支援時跳出存檔視窗，選的檔名就是作品名稱（分頁跟著改）；之後 Ctrl+S 直接覆寫同一個檔案，另存新檔（Ctrl+Shift+S）重新選。
- 開啟專案時，作品名稱用檔名。

## 部位參數（動態）
- 總體：延遲、頻率（小扳手 = 曲線）、旋轉角度、縮放；進階（摺疊）：位移距離 / 位移角度（0° = 上下）、壓扁拉伸 / 拉伸角度、轉軸角度 / 轉動頻率（翻轉）。
- 鍊：節點間延遲、擺動距離、鬆度、頻率（也有小扳手）、圓度、慣性。
- 「總體」「鍊」標題左邊的圓點 = 整組開關；底下「重設」「設為預設」（存在這台電腦，之後新增同類型就用這組）。
- 頻率不是整數時：輸出會自動往下多播幾段（不是重複同一段），播到所有動作剛好接回起點。

## 規則
- 五官（臉、眼睛、鼻子、口、眉毛）只能放在「頭」底下；其他地方新增或換父層時，五官選項會灰掉。
- 名稱不能重複（新增時自動加編號，改名成重複的會被擋下）。
- 立體沒啟用時，立體分頁全部灰掉。

## 差分與眨眼
- 差分：屬性顯示縮圖、切換方式（直接 / 淡入 / 彈入）、時間軸、刪除；出現時間在時間軸上是一條橫條，拖曳移動、拖兩端調長度。
- 眨眼只出現在「眼睛」圖層（設定眨眼）與「頭」（圈出眼睛：套索圈、筆刷微調、確定後才分成圖層）。
- 眨眼樣式：一般（預設 4 幀，2 – 6）、慢眨（11 幀，8 – 14）、瞇眼（14 幀，8 – 24）；時間軸上雙擊加、拖右端調長短、右鍵換樣式。

## 時間軸
- 雙擊新增 / 刪除影格；位移 X / Y 與旋轉一起加刪移動，縮放 X / Y 綁定。
- 時間尺左右拖 = 拉播放頭；空白處拖曳 = 框選多個影格（一起移動、Delete 刪除）。
- 標題列：− N 個循環 +、全部曲線、全部清除；縮放拉桿在右下角（中間 = 剛好放滿）。

## 圖層群組
- 只存在於圖層區，只綁定前後順序；和部位樹的父子關係無關，所以不同父層的圖層也能組在一起（資料：data.lgroups，圖層的 lg）。
- 群組裡的圖層一定相鄰；拖圖層到群組內的圖層上 = 加入、拖到外面 = 移出；拖群組標題 = 整組調整前後。
- 標題列：顯示、摺疊、層數、動態開關；選取群組後，上方「不透明」拉桿調整組透明度，變形工具（T）一起移動，右側可以整組縮放。
- PSD 的資料夾與舊版的群組會自動轉成圖層群組。

## 影格位置
- 存成循環的 1/64 格（改 BPM 時位置跟著循環走），顯示與播放都對齊到最近的一幀。

## 存檔格式
- 名稱_tan.png：一般的 PNG（作品縮圖，電腦相簿可以直接看）＋ 完整專案（PNG 裡的 tnDz 區塊）。舊的 .彈design.png、_tan.apng 照樣能開。

## 快速建模（測試中，左上角選單）
- 分層：每個圖層選物件屬性（和「物件屬性」同一套類型），依手動調好的範例（觸手範本、白髮女孩）建立層次：
  身體圖層 → 軀幹部位（脊椎鏈，從下巴往下）→ 頭圖層 → 頭部位（支點在下巴，延遲 4）→ 頭髮 / 五官 / 耳朵圖層。
  下巴：頭圖層下緣輪廓在重心附近最低的地方；頭髮沿形狀垂下；尾巴 / 觸手 / 飾品 / 手臂：每一塊、每一條分支從靠近身體重心的一端長一條鏈（沿形狀中間）。
  腿不跟著軀幹擺；沒有指定「頭」時，臉的圖層自動當頭。
- 單張：點軀幹 → 點下巴 → 加頭髮（不再加手臂）；↶ 或 Backspace 復原一步。
- 視窗可以拖曳；開著時其他工作區變暗。

## 魔術棒（W）
- 點圖層選取顏色相近的區塊（Shift 加選、Alt 減選）；容許度、柔邊、擴張 / 收縮、只選相連的；Delete 或「刪除選取」挖掉選到的區塊（可以 Ctrl+Z 復原）。

## 整體流程
1. 主頁：「＋ 新增」、近期存取（存檔或開啟專案後出現，存在這台電腦的瀏覽器，顯示會動的預覽），後面接著範例。左上角選單 →「主頁」回來。
2. 新增：
   - 完整模式：開啟圖片 / PSD / 專案，用全部的工具自己建（現在的介面）。
   - 快速建立 · 無分層（單張圖）／有分層（PSD）：選檔 → 快速建模（Q 版 / 正常比例，差在預設參數）→ 進簡易模式。
3. 簡易模式 ↔ 完整模式：右上角按鈕或左上角選單切換。簡易模式目前：物件清單（顯示 / 動態開關，不分父子）＋ 屬性（動態 / 立體分頁，內容待建立）。

## 快速建模（單張）
- 軀幹、下巴（必要）；頭髮、肚臍（選配：以下用下半身的動法，輕微反向擺）、獸耳、尾巴（點根部再點末端，或按住拖）。
- 勾選：頭髮擺動、其他東西擺動（獸耳、尾巴、下半身）。單張圖不套用立體。
- 分層另外有：深度、頭部定位、BPM。

## 簡易模式
- 不能選部位、加錨點、改範圍；隨時在播放，不用切換編輯 / 預覽。
- 版面：電腦 = 左邊畫面＋播放列、右邊上方圖層（顯示、不透明度、深度，和完整模式同一個圖層區）、下方類型分頁；手機（窄）= 畫面在上、分頁在下，圖層從畫面右上角的按鈕叫出。
- 分頁 = 圖上有的類型（整體、頭、頭髮、耳朵、五官、軀幹、下半身、手臂、尾巴、飾品）；每個類型：整類動態開關＋三個參數
  - 幅度：鏈 = 擺動距離 0 → 5%、鬆度 0 → 1、圓度 0 → 15%；沒有鏈的（頭等）= 旋轉角度 0 → 預設的兩倍
  - 頻率：總體與鍊一起；延遲：總體延遲與鍊的節點間延遲一起
  - 其餘參數保留預設，慣性 0.2
- 整體：整體動作、時間軸、外框（不顯示整體運動、緩動、網格）；往下是立體：啟用後只有深度感、左右角度、產生深度。

## 簡易模式（更新）
- 新增 → 快速建立：直接進簡易模式；快速建模放在右側邊欄（手機在下方欄位），不擋畫面。取消 = 回主頁、不保留。
- 快速建模步驟：一條線串起來；必填（軀幹、下巴）設定完自動跳下一步；其他步驟右下有「跳過」（設定了變「完成」）；必填都完成後出現「建立」。取消在左下。
- 頭髮：範圍往上下各延長一點，三個節點。
- 建立完每個類型的幅度 = 40%：鏈 = 擺動距離 0 → 25%（正常比例 18%）、鬆度 0 → 1、圓度 0 → 8%；沒有鏈的 = 旋轉角度（40% = 建立時的角度）。
- 每個類型：動態、幅度、頻率、延遲、範圍（50 … 200%；遮罩範圍也會往外 / 往內長，從原本遮罩的複本算，100% 回到原樣）。
- 畫面左上角兩個開關：錨點（全部顯示，可以拖曳，不能新增或刪除）、範圍（目前分頁的類型；整體分頁 = 全部）。
- 圖層區約五格高，電腦版可以拖下緣調整高度（記住）。
- 整體：不分區塊；多圖層才有立體。
- FPS 移到左上角選單 →「設定」（預設 30）；算 BPM 先拿掉。
- 窄螢幕（手機）開任何檔案都先用簡易模式；手機切到完整模式會要求橫向（能鎖就鎖，不能鎖就顯示「請把手機轉成橫向」）。
- 寬螢幕的簡易模式：側邊欄左緣可以拖曳調整寬度（和完整模式右側欄共用寬度）。

## 單圖層快速建立 + 多圖層檔案
- 在「快速建立 · 單圖層」選了多圖層的檔案（例如 PSD）：先壓成一張圖再編輯。
- PSD：用檔案裡的合併影像（繪圖軟體存的樣子，含混合模式、剪裁遮色片、資料夾、效果、調整圖層）；檔案沒有合併影像時自己疊：隱藏的圖層 / 資料夾、不透明度、常見混合模式、剪裁遮色片。

## 混合模式與剪裁遮色片（圖層）
- 圖層屬性：混合模式（正常、變暗、色彩增值、加深顏色、線性加深、變亮、濾色、加亮顏色、線性加亮、覆蓋、柔光、實光、強烈光源、線性光源、差異化、排除、減去、分割；公式同 Photoshop / W3C，先把畫好的內容複製成底圖再用公式合成）、剪裁遮色片（只顯示在下面那個圖層的範圍內；和 Photoshop 一樣，底層 = 前後順序上下面最近的非剪裁圖層，底層隱藏時剪裁的也不顯示）。圖層列右鍵也能切換剪裁。
- 做法參考 Live2D：底層圖層（目前變形的樣子）先畫到遮罩畫面，剪裁的圖層只畫在遮罩有 alpha 的地方，所以跟著動作也剪得正確。
- 匯入 PSD：剪裁與上面的混合模式直接帶進來；有不支援的（色相、飽和度、顏色、明度、小光源、實色疊印混合、溶解等）時會問：照原樣導入（用正常模式）或忽略這些圖層。

## 手機
- 載入時先看到主頁；開檔完成才收起主頁（手機直接進簡易模式，不會先閃一下完整模式）。全部分頁關掉回主頁。
- 網頁本身不能兩指縮放；預覽畫面可以兩指縮放、一指拖曳平移（簡易模式）。
- 完整模式的分隔線加大觸控範圍，可以用手指拖曳調整區塊大小。
- 手機快速建模：短按才加點、單指拖 = 一筆（頭髮等）、兩指 = 縮放（不會誤加點）；每個步驟有垃圾桶，清掉那一步的點 / 線。
